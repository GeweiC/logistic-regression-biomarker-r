# Portfolio figures

Selected preview charts included in this folder:

- `observed_biomarker_proportions.png`
- `raw_quadratic_fit.png`
- `log_biomarker_fit.png`
- `model_curves_comparison.png`
- `in_sample_accuracy.png`

The included PNG previews were **independently reconstructed during portfolio preparation** from the grouped count dataset using Python/Matplotlib, for cross-checking and display. The R scripts generate equivalent base-R figures under the **same filenames** once the authorised `data/immune.csv` file is supplied locally. Thus these preview files should not be described as images originally rendered by R.

All reported accuracies are **in-sample**; there is no held-out evaluation in the original coursework.
